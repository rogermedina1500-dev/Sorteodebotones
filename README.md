# Elige tu destino 🎲

Una aplicación web interactiva desarrollada con **HTML5**, **CSS3** y **JavaScript**.

## Características
- **Título principal:** "Elige tu destino"
- **Dos botones principales:** Un botón rojo y un botón azul con animaciones y efectos interactivos.
- **Resultado aleatorio:** Al hacer clic en un botón, muestra de forma aleatoria *"Has ganado"* 🎉 o *"Has perdido"* 💥.
- **Botón para volver a jugar:** Restablece la partida con una transición suave.
- **Diseño limpio y moderno:** Centrado vertical y horizontalmente, responsivo para dispositivos móviles y escritorio con estética cuidada.

## Cómo ejecutar la aplicación
Abre el archivo `index.html` directamente en tu navegador web preferido (Chrome, Edge, Firefox, Safari).
